# Lumen v0.16.1 — Windows release build fix

This patch replaces the incomplete v0.16.0 release candidate. It includes
all [v0.16.0 operator workflows](https://github.com/ravirann/lumen/blob/v0.16.1/docs/release/v0.16.0.md)
and the native-core changes since the last public v0.14.0 release.

## Fix

The Windows build rejected an unused parameter in connection diagnostics:
its only use was compiled on Unix, and the release build treats warnings as
errors. Marking that conditional use fixes compilation without changing
executable detection behavior or weakening warning checks.

CI now checks the native Windows application with warnings denied on pull
requests and during exact-commit release verification, before creating a tag
or packaging installers.

## Release status and known limits

The v0.16.0 tag remains unchanged; its incomplete draft is not published.
This release builds fresh macOS, Linux, and Windows assets under v0.16.1.
The operator-workflow limitations and upstream dependency warnings documented
in the v0.16.0 notes still apply.

The release remains a draft until asset validation and platform installation,
upgrade, and signing checks are complete. See the
[release checklist](https://github.com/ravirann/lumen/blob/v0.16.1/docs/release/RELEASE_CHECKLIST.md).
